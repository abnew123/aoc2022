# aoc2022

Java solutions for Advent of Code 2022.

## Running solutions

Select the `days` and `parts` arrays in `src/aoc2022/MasterSolver.java`, then run `aoc2022.MasterSolver` from the repository root so it can read `data/dayNN.txt`.
